# AI WeChat Agent (基于AI的微信自动聊天)

本项目是一个基于 Python 的微信 Windows 客户端自动化代理，旨在通过 AI 赋能实现微信消息的自动回复、群聊监控及聊天记录存储。

> **当前适配版本**：微信 Windows 4.1.1.19 启动失败请先启动windows讲述人功能，跑通后关掉即可
> **核心技术栈**：Python, `pywinauto`, `pyautogui`, `pywin32`, SQLite3

---

## 🚀 已实现功能

### 1. 个人 AI 自动回复 (`ai_chat.py`)
- **自动轮询**：实时检测指定联系人的最新消息。
- **智能识别**：能够区分发送方（左侧）和自己（右侧），仅对对方消息进行响应。
- **即时回复**：当前示例会简单地在消息后追加 "+AI" 进行回复（可轻松接入 LLM API）。

### 2. 群聊 AI 助手 & 记录器 (`group_chat_ai.py`)
- **群组监控**：在指定的群聊中监听所有成员的消息。
- **发送者识别**：通过 UIA 控件树与像素分析（Pixel Analysis）精准识别消息发送者。
- **自动响应**：支持对群组内其他成员的消息进行 AI 自动回复。
- **消息持久化**：所有接收和发送的消息均自动记录到本地 SQLite 数据库中。

### 3. 微信 UI 自动化核心 (`wechat_utils.py`)
- **窗口管理**：自动查找并激活微信主窗口。
- **导航控制**：支持侧边栏导航（聊天、通讯录等）。
- **精准搜索**：通过搜索功能快速定位并打开联系人或群组。
- **消息收发**：
    - **读取**：解析聊天气泡，提取文本内容。
    - **发送**：模拟剪贴板粘贴与快捷键（Alt+S）发送，支持中文及特殊符号。
- **侧边检测**：利用屏幕取色技术判断消息属于“左侧（他人）”还是“右侧（自己）”。

### 4. 数据存储与分析
- **本地数据库**：自动创建并维护 `wechat_chat.db` (SQLite)，存储字段包括聊天名称、发送者、消息内容、消息方向（Side）及时间戳。

### 5. UI 探索与调试工具 (`explore_wechat.py`)
- **UIA 树快照**：打印微信内部 UI 控件树，用于适配新版本或定位控件。
- **调试支持**：包含自动截图功能，用于分析 GPU 渲染区域。

## 🛠️ 安装与使用

### 环境准备
1. 确保系统为 Windows (win32)。
2. 本项目推荐使用 [uv](https://github.com/astral-sh/uv) 进行项目管理。
3. 确保微信已登录且版本为 `4.1.1.19`（其他 4.x 版本可能需要微调）。

### 安装与同步
在项目根目录下运行以下命令：
```bash
# 同步依赖并创建虚拟环境
uv sync
```

### 运行说明
使用 `uv run` 执行脚本：
- **启动个人聊天助手**：
  ```bash
  uv run ai_chat.py "联系人昵称"
  ```
- **启动群聊助手（带日志记录）**：
  ```bash
  uv run group_chat_ai.py "群聊名称"
  ```

## 📂 项目结构
- `main.py`: 项目入口（占位）。
- `wechat_utils.py`: 核心工具库，封装了所有 UI 操作。
- `ai_chat.py`: 单人聊天业务逻辑。
- `group_chat_ai.py`: 群聊监控与回复逻辑。
- `explore_wechat.py`: UI 探索脚本。
- `ref/`: 包含 AI 提示词、UI 探索指南等文档。
